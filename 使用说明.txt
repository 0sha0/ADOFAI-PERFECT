ADOFAI PERFECT v1.2 - 使用说明
================================

■ 运行环境
  · Windows 10 / 11 x64，Steam 版《A Dance of Fire and Ice》
  · 发布版为静态 CRT，无需安装 VC++ 运行库，纯净系统解压即用
  · 需要 .NET 吗？不需要（纯 C++ 模块）

■ 使用方法
  1. 启动游戏（到标题画面即可）
  2. 双击 run.cmd（或直接运行 Injector.exe）注入
     Injector 会自动等待游戏与 Mono 就绪（最长 10 分钟）
  3. 游戏内出现悬浮面板后：
     · Insert 键：显示 / 隐藏面板
     · End   键：卸载工具并还原游戏

■ 面板页面（页签顺序）
  功能 / 状态 / 读谱 / 4K / 5K / 6K / 10K / 按键 / 皮肤 / 录制 / 宏模式 / 设置 / 关于
  · 4K / 5K / 6K / 10K：无轨谱面实时转下坠谱，默认键位 DFJK / SDFJK / SDFJKL / ASDFG+HJKL;
    每套可单独选转换风格：经典 / 叠 / 技 / 乱 / 切 / 冰火手法
    另有上隐 / 下隐 / 自动调整延迟 / 判定宽度（宽·中·严）/ 一键校准 / 自动打歌 / 宏打歌
  · 按键：KeyViewer 式按键反馈（次数 / KPS / 自定义键位 / 位置缩放）
  · 录制：小窗录制游戏原生画面 —— 开始 / 暂停 / 继续，可设输出目录、帧率、码率
  · 宏模式：冰与火模式（宏直接代打游戏本体判定线，成绩真实非 100%）
             + 4K/5K/6K/10K 宏打歌；可设目标精准度、拟人程度、按歌曲一键校准
             勾选冰与火模式后开局无需人工按键，工具会自动开始关卡
  · 设置：选择游戏目录、切换语言（简中 / 繁中 / English / 日本語 / Русский）、
          整套配置保存 / 加载
  · 关于：LOGO / 名称 / 版本 1.2；打开本页会自动跳转演示视频

■ 目录说明
  Injector.exe          注入器（必须与 ADOFAIPerfect.dll 放在同一目录）
  ADOFAIPerfect.dll     功能模块（覆盖层 + 4K/5K/6K/10K + 皮肤系统，内嵌 LOGO）
  skin\                 内置皮肤（请勿删除；换皮肤只需在「皮肤」页导入 .msp）
  configs\              配置档案目录（首次保存时自动创建）
  adofai_perfect.cfg    设置文件（首次保存设置时自动生成，不存在=默认设置）

■ 皮肤
  · 默认使用内置皮肤（开箱即用，且不受外部皮肤影响）
  · 想用外部 Malody .msp 皮肤：皮肤页 → 导入 MSP 皮肤…，或把皮肤文件夹放进 skin\ 后点「重新扫描」
  · 皮肤目录解析顺序：环境变量 ADOFAI_PERFECT_SKIN → adofai_perfect.cfg 的 skin_dir= →
    运行目录 skin\

■ 常见问题
  · 报错缺少 vcruntime140.dll？本版本不需要 VC 运行库，请确认使用的是本包内的 exe
  · 找不到游戏目录？面板 → 设置 → 选择冰与火之舞游戏目录
  · 注入被拦截？注入器需 CreateRemoteThread 权限，被杀软 / Defender 拦截时请放行
  · 转谱失败 / 谱面不动？请先真正进入关卡再打开对应模式的开关
  · 日志：%LOCALAPPDATA%\ADOFvec\adofai_perfect.log

ADOFAI PERFECT v2.1 - 使用说明
================================

■ 运行环境
  · Windows 10 / 11 x64，Steam 版《A Dance of Fire and Ice》
  · 发布版为静态 CRT，无需安装 VC++ 运行库，纯净系统解压即用
  · 需要 .NET 吗？不需要（纯 C++ 模块）

■ 使用方法
  1. 启动游戏（到标题画面即可）
  2. 双击 run.cmd（或直接运行 Injector.exe）注入
     Injector 会自动等待游戏与 Mono 就绪（最长 10 分钟）
  3. 游戏内出现悬浮面板后：
     · Insert 键：显示 / 隐藏面板
     · End   键：卸载工具并还原游戏

■ 面板结构（侧边栏 + 子导航）
  左侧为 8 个侧栏项，点击切换页面：
    基础功能 / 实时状态 / 辅助读谱 / 一般轨道 / 其他 / MOD 管理器 / 设置 / 关于
  · 窗口左上角品牌区可拖动，右下角可缩放
  · 「一般轨道」「其他」会在顶栏标题右侧展开子导航

  · 基础功能：不死模式、自动连打（卡片 + 右侧开关），以及一键卸载并还原游戏
  · 实时状态：关卡名 / 游戏状态 / 进度 / 实时 Acc 与 XAcc / 死亡次数 / 检查点 / 实时角度与 BPM
  · 辅助读谱：无轨读谱辅助（侧边 / 底部横条 / 顶部 / 居中；中旋为蓝色；可调提前量与密度、时间网格、校准）

  · 一般轨道（子导航：选择 / 4K / 5K / 6K / 10K / 8K / 16K(PAD) / CATCH / OSU!）
    · 4K / 5K / 6K / 10K：无轨谱面实时转下坠谱，默认键位 DFJK / SDFJK / SDFJKL / ASDFG+HJKL;
      每套可单独选转换风格：经典 / 叠 / 技 / 乱 / 切 / 冰火手法
      另有上隐 / 下隐 / 自动调整延迟 / 判定宽度（宽·中·严）/ 一键校准 / 伪双押优化 /
      硬抗 BPM / 内轮指（仅风格选「冰火手法」时出现）/ 录制
      · 冰火手法引擎按模式真实键位分工（5K=3+2 / 6K=3+3 / 10K=5+5），不会退化成 4K
      · 伪双押优化：把冰与火的 15°/30° 伪双押生成成真·同刻双押；判据 = 尖锐角(转角≤30°)
        且间隔极近(≤45ms)。因 Δt = 转角/180° × 30/(BPM×speed)，固定 45ms 窗口等价于
        角度上限随 BPM 自动伸缩（慢歌的 30° 装饰音不再被误合并；面板实时显示等效角度上限）；
        只合并「单发」小角步，连发小角 = 快轮，保持原样不误判
      · 键位支持非字母/数字键（; ' [ ] 、空格、ENTER 等）
      · 本页不再出现「宏打歌」开关，宏打歌统一在「其他 → 宏模式」页选
    · 16K（PAD）：Malody Pad 式 4×4 方形面板（非下落式），16 个方块各自收缩、缩到边界按下方块键，
      每方块可单独设键；独立谱面算法，六种经典 16K 写谱手法可换：
      经典（邻接移动 + 双手分区）/ 绕环（沿外圈 12 板回旋，方向跟星球转）/ 
      阶梯（行·列·对角线单调阶梯，端点折返）/ 十字（沿十字臂行走的图形谱）/ 
      交互（双板 trill）/ 冰火拆手序（火=左两列、冰=右两列逐砖严格交替，
      押按拆手序分配：第 1 点当前手区、第 2 点另一手区依此类推）
      · 该模式只使用内置皮肤（外部 MSP 是为轨道写的，套面板会错位）
    · CATCH：无轨道下落雨 —— 没有轨道 / 没有键位分区 / 不需要绑键
      · 鼠标左右移动控制底部接盘，雨点落到判定线的瞬间被盖住即自动接住（正中 MARVELOUS / 靠边 PERFECT·GOOD）
      · 冰火的长转渲染成长阶梯（该连的不散），大回转才是折返大跳
      · 判定同步给冰与火本体：PERFECT→Perfect、GOOD→Good（并显示快/慢）、MISS→本体也 MISS 并断连击
      · MISS 只显示判定、不会自动重开，继续游玩即可（是否致死看本体判定与「基础功能」的不死开关）
      · 生成手法可选：经典 / 走(Walk) / 冲(Dash) / 超冲(Hyper) / 边冲(Edge) / 阶梯(Stair)（模式页切换）
      · 固定使用内置 Malody 原皮 Dylamo 皮肤
    · 8K：ASDF + JKL; 标准 8 键下坠谱，独立 8 键引擎（16 音内外波浪循环 + 楼梯交替 +
      最外键 A / ; 重音），八键用量均匀、双手互不抢键；键位与皮肤独立成页
    · OSU（戳泡泡）：osu!standard 泡泡玩法 —— 512×384 判定场按 osu! 原版
      640×480 game pixel 缩放（高分辨率下视觉大小不变）；鼠标瞄准 + 左/右键（或 Z / X）点击泡泡，
      判定环缩到外圈重合时命中；判定窗按 OD（300 = 80-6*OD · 100 = 140-8*OD · 50 = 200-10*OD · 超窗 MISS），
      结果同步回冰与火本体（300/100→Perfect、50→Good 并显示快/慢、MISS→本体也 MISS 断连击）
      手法可选：经典 / 跳(Jump) / 串(Stream) / 交互 / 双押 / 技术；只用内置 osu! 皮肤
  · 其他（子导航：宏模式 / 录制 / 直播模式 / 皮肤 / 按键反馈）
    · 宏模式：冰与火模式（宏直接代打游戏本体判定线，成绩真实非 100%）
              + 4K/5K/6K/10K/8K/16K(PAD)/CATCH 宏打歌；可设目标精准度、拟人程度、按歌曲一键校准
              勾选冰与火模式后开局无需人工按键，工具会自动开始关卡
    · 录制：录制游戏原生画面 + 系统声音（AAC 48kHz 立体声，与画面同一时间基准）
            开始 / 暂停 / 继续（在菜单 / 任意界面点开始都会立刻起录，不必先进入关卡），可设输出目录（「浏览」选择、「预览」直接在资源管理器打开当前输出目录，地址存进配置文件）、帧率、码率
    · 直播模式（「其他」页独立的一张卡片）：推流 / 录像时隐藏本工具的各类叠层（ImGui 面板 / 一般轨道辅助 / 辅助读谱等）
            本机人眼照常看得到，只有 OBS / Bilibili 直播姬等采集端拍不到；开启后推送画面左上角显示 "ADOFAI-PERFECT" 水印；各项随配置档案保存
    · 皮肤：先选模式（4K / 5K / 6K / 10K / 8K / 16K(PAD) / CATCH；OSU 固定内置 osu! 皮肤），每模式独立互不通用
    · 按键反馈：KeyViewer 式按键反馈（次数 / KPS / 自定义键位 / 位置缩放 / 长按拖尾雨）

  · 设置：界面风格（6 套强调色）、切换语言（简中 / 繁中 / English / 日本語 / Русский）、
          选择游戏目录、整套配置保存 / 加载、键位说明
  · 关于：LOGO / 名称 / 版本 2.1 / 演示视频 / GitHub / 配置目录（需手动点击，不会自动跳转）

  · MOD 管理器：默认安装「官方 UnityModManager 0.32.5 内核」（MIT，随包分发，装到
    <游戏>_Data\Managed\UnityModManager，与 MOD-MANAGER 装出来的布局完全同款），
    工具通过自研桥接 Sidecar（AdofPerfectUmm.dll）驱动它 —— MOD 100% 原生兼容；
    自研兼容加载器仅作旧安装的兼容运行时保留（umm\legacy\）：
    · 扫描 MOD 目录（默认 <游戏目录>\Mods，页面里可改成任意目录，例如 D:\Games\ADOFAI MODS）
    · 按 Info.json 识别 MOD、按 Requirements / LoadAfter 拓扑排序后统一加载，符合 UMM 规范
      的 MOD 都能加载（Harmony / ModSettings / OnToggle / OnGUI / OnUpdate 等接口全部实现）
    · 每个 MOD 一张卡片：状态点 / 版本 / 作者 / 关闭 / 打开界面 / 删除；点卡片右侧箭头展开
    · 展开后可编辑该 MOD 的设置（<X>Settings.xml / Setting.xml / Settings.json / Config.json…）
      点「保存设置」会先写回设置文件，再热应用进正在运行的 MOD —— 参数与语言立即生效，
      不必重启游戏（MOD 自己有界面时也可用「打开界面」）
    · MOD 开关状态与 MOD 设置会随「设置 → 配置档案」一起保存，下次读档自动写回并热应用
    · 与原版 UnityModManager 共存（v2.0 起）：
      - 检测到原版 UMM（doorstop_config.ini 指向 Managed\UnityModManager）时，
        本工具绝不覆写它的启动配置，也绝不把 MOD 重复加载第二遍；
        游戏内加载器转入「复用模式」：MOD 列表 / 开关 / 打开界面 / 设置热应用
        全部通过反射直接作用于原版 UMM 加载的那一批 MOD，两套工具看到的是同一份状态
      - 存储与原版 UMM 完全互通，生态可直接迁移：配置读 Config.xml、
        MOD 启用状态读写 Params.xml（原版目录里已有就接手，本工具改动会镜像回原版目录）、
        MOD 设置读写 <MOD>\Settings.xml（老版本写过的 <类名>.xml 会自动升级迁移过去）
      - 没装原版 UMM 时行为不变：由本工具的加载器在游戏启动前加载 MOD

■ 目录说明
  Injector.exe          注入器（必须与 ADOFAIPerfect.dll 放在同一目录）
  ADOFAIPerfect.dll     功能模块（覆盖层 + 4K/5K/6K/10K/8K/16K/CATCH/OSU，内嵌 LOGO）
  KSkin\                内置轨道皮肤（4K/5K/6K/10K/16K；请勿删除）
  CatchSkin\            内置 CATCH 皮肤（Malody 原皮 Dylamo；请勿删除）
  umm\                  MOD 加载器（UnityModManager.dll 等；MOD 管理器要用，请勿删除）
  configs\              配置档案目录（首次保存时自动创建）
  adofai_perfect.cfg    设置文件（首次保存设置时自动生成，不存在=默认设置）

■ 界面风格
  · 侧边栏 + 子导航 + 半透明面板（Etherium 风格），控件全部为自绘，不依赖系统原生控件
  · 设置页可切换 6 套强调色：灰蓝 / 橄榄 / 青苔 / 深海 / 暖粉 / 琥珀
  · 窗口位置与尺寸可拖动 / 缩放，并会钳制在屏幕内

■ 皮肤
  · 每模式独立皮肤（皮肤页顶部先选模式）：4K / 5K / 6K / 10K / 16K(PAD) / CATCH 互不通用
  · 内置皮肤随发布包一起提供，按 <Injector.exe 所在目录>\KSkin、\CatchSkin 查找，
    不硬编码盘符 / 用户名 / 绝对路径 —— 换台电脑只要把这两个文件夹放在注入器旁边就能用
  · 16K(PAD) 与 CATCH 固定使用各自的内置皮肤（不支持外部 .msp）
  · 想给 4K/5K/6K/10K 用外部 Malody .msp 皮肤：皮肤页 → 导入 MSP 皮肤…，
    或把皮肤文件夹放进运行目录的 skin\ 后点「重新扫描」
  · 外部皮肤目录解析顺序：环境变量 ADOFAI_PERFECT_SKIN → adofai_perfect.cfg 的 skin_dir= →
    运行目录 skin\

■ 常见问题
  · 报错缺少 vcruntime140.dll？本版本不需要 VC 运行库，请确认使用的是本包内的 exe
  · 找不到游戏目录？面板 → 设置 → 选择冰与火之舞游戏目录
  · 注入被拦截？注入器需 CreateRemoteThread 权限，被杀软 / Defender 拦截时请放行
  · 进关卡不显示转谱谱面？
      1) 先确认 KSkin\ / CatchSkin\ 还在（被误删或被「重新生成」清掉会导致没有贴图）
      2) 要真正进入关卡后再打开对应模式的开关
      3) 换歌 / 重开一关会自动重建谱面，皮肤文件夹晚到也会自动恢复显示
  · CATCH 按哪个键？不用按键，用鼠标左右移动接盘即可（MISS 只显示判定、不会自动重开）
  · 直播模式是什么？把本工具叠层从推流采集里隐掉，人眼照常可见，并在左上角显示 "ADOFAI-PERFECT" 水印
  · 日志：%LOCALAPPDATA%\ADOFvec\adofai_perfect.log
